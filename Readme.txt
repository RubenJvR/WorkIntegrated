The application is built in c# using .net and wpf
databases include SQLite for local, and azure sql for online with syncing capabilities
To launch the application from the source code, one would have to launch the ADIX.sln in visual studio

once started you will be met with a login screen, the correct credentials are:
Username: admin
password: admin123

-- Dashboard
	afterwards there will be a dashboard giving a broad overview of the application and the state of the inventory
-- POS
	There is also the POS page where users can make payments and create invoices or quotes and then ultimately checkout 
	
-- Inventory 
	shows all the items currently in stock and allows for the importing of current data, an example of the csv can be seen in the WorkIntegrated folder called Pls.csv

-- Supplier
	shows the list of suppliers and allows the user to add new suppliers as well as make payments to specific suppliers

-- Finance
	this page allows us to make expenses as well as pay staff. And export information regarding the expenses.

-- Monthly Report

	this page will let the user look at sales across the moth and generate reports based on them

-- Sales 
	
	will display sales made

-- Staff
	
	will allow the admin to add new staff members and edit them.
